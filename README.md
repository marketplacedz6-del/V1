# 🛒 SouqiExpress | سوقي إكسبريس

منصة تجارة إلكترونية جزائرية **متعددة التجار**، مبنية بالكامل بـ **HTML + CSS + JavaScript** فقط
(بدون أي خادم أو باك-إند)، تعمل مباشرة على أي **استضافة مجانية ثابتة** مثل GitHub Pages أو Netlify.

## 🚀 النشر على الاستضافة المجانية

### الطريقة 1: GitHub Pages (مجاني بالكامل)
1. ارفع الملفات إلى مستودع GitHub.
2. من `Settings` ➜ `Pages`.
3. اختر **Source: Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
4. احفظ — سيصبح موقعك متاحاً على:
   `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

> ملف `.nojekyll` موجود مسبقاً حتى لا يتجاهل GitHub مجلد `assets`.

### الطريقة 2: Netlify Drop
اسحب مجلد المشروع كاملاً إلى https://app.netlify.com/drop — يُنشر خلال ثوانٍ.

### الطريقة 3: Cloudflare Pages / Vercel
اربط المستودع واترك أمر البناء فارغاً، ومجلد النشر: `/` (المشروع ثابت بالكامل).

## ⚙️ التخصيص السريع

كل الإعدادات في ملف واحد: `assets/js/config.js`

```js
window.SE_CONFIG = {
  siteName: "SouqiExpress",
  currency: "د.ج",
  logo: "رابط شعارك",
  social: { facebook: "...", instagram: "...", tiktok: "..." },
  firebase: { /* مفاتيح مشروعك في Firebase */ }
};
```

### مهم بعد النشر 🔐
في لوحة Firebase ➜ **Authentication ➜ Settings ➜ Authorized domains**،
أضف نطاق موقعك الجديد (مثل `username.github.io`) وإلا لن يعمل تسجيل الدخول.

كما يجب ضبط قواعد Firestore للسماح بالقراءة العامة للمنتجات وبإنشاء الطلبات:

```
match /products/{id}      { allow read: if true; }
match /categories/{id}    { allow read: if true; }
match /shipping_rates/{id}{ allow read: if true; }
match /orders/{id}        { allow create: if true; allow read, update: if request.auth != null; }
```

## 🆕 الميزات الجديدة للتجار

### 📊 ربط الطلبات بـ Google Sheets
كل طلب جديد يُضاف تلقائياً كسطر في جدول التاجر — بدون خادم ولا اشتراك.

**الإعداد (مرة واحدة):**
1. من لوحة التاجر: **الإعدادات ← ربط الطلبات بجدول Google Sheets ← 📖 طريقة الربط**
2. انسخ كود Apps Script المعروض والصقه في جدولك (`Extensions ← Apps Script`).
3. `Deploy ← New deployment ← Web app`، واضبط **Who has access = Anyone**.
4. ألصق الرابط في الحقل، ثم جرّبه بزر **🧪 إرسال سطر تجريبي**.

الأعمدة المُرسلة: التاريخ، رقم الطلب، الزبون، الهاتف، الولاية، العنوان، المنتج، الكمية، اللون، المقاس، السعر، الشحن، الإجمالي.

### 🎯 بكسل التتبّع (Facebook + TikTok)
يكفي إدخال الـ Pixel ID في الإعدادات، وتُطلق الأحداث تلقائياً:

| الحدث | Facebook | TikTok |
|---|---|---|
| مشاهدة منتج | `ViewContent` | `ViewContent` |
| إضافة للسلة | `AddToCart` | `AddToCart` |
| بدء الطلب | `InitiateCheckout` | `InitiateCheckout` |
| إتمام الشراء | `Purchase` | `CompletePayment` |

كل الأحداث تُرسل بقيمة الطلب وعملة `DZD`.

### 🚀 صفحة الهبوط (Landing Page)
صفحة تسويقية جاهزة لكل تاجر على الرابط:
`landing.html?merchantId=معرّف_التاجر`

تتضمّن: عنوانًا ونصًّا قابلين للتخصيص، **صورة غلاف تُرفع مباشرة من جهازك** (تُضغط تلقائيًا)، عدّاد تنازلي، شارات ثقة، منتجات المتجر، آراء زبائن، وزر واتساب عائم.
تُدار من **مركز التاجر ← 🚀 صفحة الهبوط** مع **معاينة مباشرة** (هاتف/حاسوب) ونسخ الرابط بضغطة.

**رفع الصورة:** اضغط على منطقة الرفع واختر صورة من جهازك — تُضغط تلقائيًا (حتى 1200px) وتُخزَّن داخل Firestore، فلا حاجة لأي خدمة استضافة صور خارجية.

### 🏬 مركز التاجر الموحّد
| الصفحة | الوظيفة |
|---|---|
| 📊 لوحة القيادة | مؤشرات، مقارنة بالفترة السابقة، رسوم، أفضل المنتجات والولايات |
| 📦 إدارة المنتجات | تفعيل/إيقاف، مخزون سريع، نسخ منتج، نسخ الرابط |
| 🛒 الطلبات الواردة | فلاتر، بحث، واتساب، شحن، تصدير |
| 👥 **الزبائن** (جديد) | يُبنى تلقائياً من الطلبات: الأوفياء ⭐ والمتعثّرون ⚠️ ونسبة التأكيد |
| 🚚 إدارة الشحن | تسعير جماعي + ربط شركات التوصيل |
| 🚀 صفحة الهبوط | محرّر ومعاينة مباشرة |
| ⚙️ الإعدادات | Sheets، بكسلات، حماية، بوابة الشحن |

**تحسينات بنيوية:**
- `assets/js/merchant-shell.js` — شريط جانبي واحد وحماية موحّدة بدل تكرارهما في 7 صفحات.
- **بحث سريع (Ctrl + K)** — تنقّل فوري بين الصفحات والزبائن.
- شارة الطلبات المعلّقة تظهر في القائمة الجانبية من أي صفحة.

### 🚚 الربط مع شركات التوصيل الجزائرية
يدعم **Yalidine · ZR Express · Maystro · NOEST · Ecotrack** (وأكثر من 30 شركة على منصة Ecotrack).

**الربط:** من **إدارة الشحن ← الربط مع شركة التوصيل** → اختر الشركة، أدخل مفاتيحها، اضغط **🔌 اختبار الاتصال** ثم **💾 حفظ الربط**.

| ما يمكنك فعله | أين |
|---|---|
| جلب الأسعار الرسمية لكل ولاية | إدارة الشحن ← 🔄 جلب الأسعار من الشركة |
| إرسال طلب للشحن + رقم تتبّع | الطلبات ← 🚚 إرسال للشحن |
| إرسال كل الطلبات المؤكدة دفعة واحدة | الطلبات ← 📦 إرسال كل الطلبات المؤكدة |
| إرسال تلقائي عند تأكيد الطلب | خيار في إعدادات الربط |
| تتبّع الشحنة | الطلبات ← 📍 رقم التتبّع |

**بديل مضمون بلا مفاتيح:** من الطلبات اضغط **🚚 تصدير لشركة التوصيل** (صيغة Yalidine أو عامة) وارفع الملف في لوحة الشركة. يعمل دائماً.

> الاتصال يمر عبر بوابة موحّدة (`freeship.dzbuild.com` افتراضياً) لأن الموقع ثابت بلا خادم.
> مفاتيحك تُستعمل لإنشاء الطرد على **حسابك أنت** ولا تُخزَّن لدى البوابة.
> يمكنك تغيير البوابة من **الإعدادات ← بوابة شركات التوصيل**.
> إن حجب المتصفح الطلب (CORS)، تظهر رسالة واضحة وتستطيع استعمال التصدير CSV.

### 🛡️ الحماية من الطلبات الوهمية
أربع طبقات تعمل معاً:

1. **تقييد حسب عنوان IP** — حد أقصى يحدده التاجر (افتراضياً 5 طلبات / 24 ساعة). يُخزَّن الـ IP **مُجزّأً (hashed)** في `order_limits` حفاظاً على الخصوصية.
2. **حد على مستوى الجهاز** — يعمل فوراً بلا شبكة.
3. **كشف التعبئة الآلية** — رفض أي نموذج يُملأ في أقل من 4 ثوانٍ.
4. **حقل مصيدة (Honeypot)** — حقل مخفي لا يملؤه إلا البوت.

> ملاحظة: عند تعذّر معرفة الـ IP أو انقطاع الشبكة، يُسمح بالطلب اعتماداً على الحد المحلي — حتى لا يُحرم زبون حقيقي بسبب خطأ تقني.

### 🔐 قواعد Firestore المطلوبة للميزات الجديدة
```
match /merchant_settings/{id} { allow read: if true; allow write: if request.auth != null; }
match /order_limits/{id}      { allow read, write: if true; }
```
