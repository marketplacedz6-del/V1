> فُحصت هذه القائمة على الملفات الفعلية، لا من الذاكرة.
> **إجمالي ما يحتاج تعديلاً منك: 3 أشياء فقط.** الباقي جاهز.

## 🔴 إلزامي — بدونها المنصة غير آمنة أو ناقصة

### 1. قواعد أمان Firestore ← الأهم على الإطلاق

**الملف:** `firestore.rules` (موجود في المشروع)
**لا يُرفع مع الموقع** — يُطبَّق في Firebase.

**الخطوات:**
```
Firebase Console → مشروعك (walid-shop)
→ Firestore Database → تبويب Rules
→ احذف الموجود والصق محتوى firestore.rules كاملاً
→ Publish
```

**لماذا حرجة؟**
المنصة HTML ثابت بلا خادم، فكل فحوصات الواجهة (الاشتراك، الصلاحيات، النقاط) **يمكن تجاوزها من أدوات المطوّر في المتصفح**. بدون هذه القواعد يستطيع أي شخص:
- تمديد اشتراكه مجاناً
- ترقية نفسه إلى `admin`
- تعديل أو حذف منتجات وطلبات تاجر آخر

> ⚠️ **لا تُطلق حملة إعلانية قبل تطبيقها.**

### 2. النطاق الحقيقي (بعد رفع الموقع ومعرفة رابطك)

**ملفان فقط:**

| الملف | السطر | القيمة الحالية |
|---|---|---|
| `sitemap.xml` | 8 روابط | `https://souqiexpress.example/...` |
| `index.html` | 54 | `"url": "https://souqiexpress.example"` |

**إن كنت على GitHub Pages** فرابطك غالباً:
```
https://marketplacedz6-del.github.io/V1
```

**أسرع طريقة** — نفّذ هذا بعد استبدال النطاق:
```bash
sed -i 's|https://souqiexpress.example|https://نطاقك-الحقيقي|g' sitemap.xml index.html
```

**لماذا؟** بروتوكول Sitemap يشترط روابط مطلقة. بالعنوان الوهمي **تتجاهل Google الملف كلياً** ولا تُفهرس صفحاتك.

### 3. رابط Google Sheets (لكل تاجر على حدة)

هذا **يفعله كل تاجر بنفسه** من لوحته، لا أنت.

```
مركز التاجر → الإعدادات → انسخ كود Apps Script
→ الصقه في script.google.com
→ Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy
→ انسخ رابط /exec والصقه في خانة الإعدادات
```

> ⚠️ **الخطأ الأكثر شيوعاً:** لصق الكود دون إعادة النشر. Google يبقى على النسخة القديمة.
> **للتأكد:** افتح رابط `/exec` في المتصفح — يجب أن يظهر `SouqiExpress webhook is live`.

## ✅ اختبار بعد النشر (5 دقائق)

- [ ] افتح `الموقع/index.html?fresh=1` مرة واحدة (يمسح الكاش القديم)
- [ ] سجّل حساب تاجر تجريبي — تأكد أن الاسم والهاتف والشعار **مطلوبة**
- [ ] فعّله من لوحة الإدارة وتأكد أن **النقاط تُخصم بعدد الأشهر**
- [ ] أضف منتجاً وأسعار شحن لولاية
- [ ] اطلب المنتج كزبون → تأكد وصول الطلب للوحة
- [ ] جرّب صفحة الهبوط: `landing.html?s=اسم-متجرك`
- [ ] افتح الموقع على **هاتف حقيقي** وتصفّح الصفحات

## 🔁 عند أي تعديل مستقبلي

إن غيّرت أي كلاس Tailwind في HTML:

```bash
npm install                 # مرة واحدة
npm run build:css           # يعيد بناء tailwind.css
```

ثم **ارفع الإصدار في 3 أماكن معاً** (وإلا بقي المستخدمون على النسخة القديمة):
1. `?v=43` في كل ملفات HTML
2. `CACHE` في `sw.js`
3. `SE_BUILD` في `assets/js/app.js`

## الخلاصة

**تعديلان منك فقط:**
1. **طبّق `firestore.rules`** في Firebase Console ← عاجل
2. **استبدل النطاق** في `sitemap.xml` و`index.html` ← بعد معرفة رابطك

وكل تاجر يربط جدوله بنفسه من لوحته.
