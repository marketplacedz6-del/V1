# أدوات البناء

## `build-css.mjs` — توليد `assets/css/tailwind.css`

الموقع **لا يستعمل `cdn.tailwindcss.com`** (نسخة Play CDN المخصّصة للتجريب فقط).
بدلاً منها نشحن ملف CSS مبنياً مسبقاً، لأن الـ CDN كان يسبّب:

- **وميض محتوى غير منسّق (FOUC)** — الصفحة تظهر عارية ثم تقفز.
- **انهيار التنسيق بالكامل** إن بطؤ الاتصال أو حُجب الـ CDN.
- تحذير Tailwind الرسمي: لا تستعملها في الإنتاج.

### متى تعيد البناء؟
كلما **أضفت كلاس Tailwind جديداً** في أي ملف HTML أو JS.

### كيف؟
```bash
npm install tailwindcss@3 postcss
node tools/build-css.mjs
```

ثم ارفع رقم الإصدار `?v=N` في كل الصفحات، وفي `sw.js` (`CACHE`)
وفي `assets/js/app.js` (`SE_BUILD`) — الثلاثة معاً.

### تحقّق من التغطية
`tools/verify-css.mjs` يقارن كل كلاس مستعمل بالملف المبني ويبلّغ عن الناقص.
